| `opening_stock` | int | stock at 00:00 IST (calculated, floored at 0) |
| `units_sold` | int | units leaving stock (orders not cancelled before dispatch) |
| `restocked` | int | units received |
| `damaged` | int | units written off |
| `adjusted` | int | net cycle-count adjustment (±) |
| `closing_stock` | int | stock at 24:00 IST (calculated, floored at 0) |

| `below_reorder_level` | boolean | closing stock ≤ reorder level |
| `is_stockout` | boolean | stock reached 0 at some point during the day |

| `reconciliation_gap` | int | counted − calculated at the count (empty for the first count) |
| `avg_daily_units_14d` | double | average units sold per day over the last 14 days |
| `days_of_inventory` | double | closing stock ÷ avg_daily_units_14d; empty if no recent sales |
